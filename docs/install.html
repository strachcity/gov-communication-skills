Claude skills

Add the 4 skills one at a time. This works on every Claude plan.

What you need

  • Claude on a computer: in your browser at claude.ai, or the Claude desktop app
  • code execution switched on. Open Settings, then Capabilities. It's on by default for most people. If it's off, the skills install and then appear to do nothing

Download

Download all 4. Leave them zipped: Claude wants each file exactly as it arrives.

  1. government-communication, the front door
  2. case-communication-patterns
  3. privacy-aware-communications
  4. govuk-content

Install it

  1. In Claude, open Customize, then Skills.
  2. Select +, then Create skill, and upload one of the zips. Do not unzip it.
  3. Check it's switched on, then repeat for the other 3.
  4. Start a new chat.

Add all 4. The front door, government-communication, uses the other 3. If you only want style reviews, govuk-content works on its own.

Claude may warn that it can't verify skills made by other people. That's correct, and it appears for everything of this kind. Everything the skills contain is readable in the skills folder on GitHub.

Check it worked

All 4 are listed under Skills and switched on. Nothing appears in your chat window, and nothing is supposed to.

Start a new chat and ask for a message for your service, like "draft an email telling someone we've received their application". It should ask about your service, or draft with placeholders and list what still needs a decision. It should not guess your timescales or policy.

If it goes wrong

It installed but seems to do nothing

Check code execution is on, in Settings, then Capabilities, and start a new chat. Skills don't load into a chat that was already open.

I have a folder, not a zip

Safari on a Mac unzips downloads on its own. Claude needs the zip, so put it back: right-click the folder and choose Compress, then upload the new zip. To stop it happening again, open Safari, then Settings, then General, and untick Open "safe" files after downloading.

The skills have been updated

Skills don't update themselves. Download the new zips, remove the old skills and upload the new ones. The plugin can update itself instead.

Claude plugin

Install all 4 skills as one plugin. You can upload it as a zip, or add it from GitHub so it updates itself.

What you need

  • Claude on a computer: in your browser at claude.ai, Cowork, or the Claude desktop app. Or Claude Code
  • a paid plan (Pro, Max, Team or Enterprise). On the free plan, use Claude skills instead
  • code execution switched on. Open Settings, then Capabilities

Install from the zip

Download the plugin (zip)

One zip. Leave it zipped. If you end up with a folder instead, see If it goes wrong.

  1. In Claude, open Customize, then Plugins.
  2. Select Add, then Upload local plugin.
  3. Drag the zip in, or browse to it, and select Upload.
  4. Wait for the security scan to finish, then switch it on.
  5. Start a new chat.

Or add it from GitHub, so it updates itself

A zip install stays at the version you downloaded. To get updates automatically, add this repository as a marketplace instead:

  1. In Customize, then Plugins, select Add, then Add marketplace.
  2. Paste this and select Sync:strachcity/gov-communication-skills
  3. Select Install next to "GOV.UK communication skills", then start a new chat.

A plugin added on claude.ai is also available in Claude Code when you sign in with the same account.

In Claude Code

/plugin marketplace add strachcity/gov-communication-skills
/plugin install gov-communication-skills@gov-communication-skills

Check it worked

"GOV.UK communication skills" is listed under Personal plugins and switched on. Start a new chat and ask for a message for your service. It should ask about your service, or draft with placeholders and list what still needs a decision.

If it goes wrong

It installed but seems to do nothing

Check code execution is on, in Settings, then Capabilities, and start a new chat. Plugins don't load into a chat that was already open.

The marketplace install fails with "Failed to fetch content: 403"

If this happens in the desktop app, try Claude in a browser first. If the browser fails too, upload the zip instead. It installs the same plugin by a different route.

I have a folder, not a zip

Safari on a Mac unzips downloads on its own. Claude needs the zip, so put it back: right-click the folder and choose Compress, then upload the new zip.

There's no Upload local plugin option

That option needs a paid plan, or your organisation may have switched it off. Use Claude skills instead: it works on every plan.

Microsoft 365 Copilot

This builds the skills as an agent in Copilot Chat. It runs on Microsoft's models with the same written rules as the Claude version. Expect it to drift from them more, especially over a long conversation. It hasn't been tested in Copilot yet.

What you need

  • a work Microsoft account with Copilot Chat
  • permission to create agents. Open Copilot Chat and look for Create agent, sometimes New agent, in the left-hand panel. If it isn't there, your organisation has switched agent creation off. Ask your IT service
  • no admin rights

Depending on your account, you add the detailed guidance as skills, as knowledge files, or not at all. The agent works in every case, with less depth the less it has.

Download

Download for Copilot (zip)

Unzip it first, unlike the Claude version. On Windows, right-click the zip and choose Extract All: opening it with a double-click isn't enough, because Copilot can't upload files from inside a zip. On a Mac, double-click it. You get a folder with the files numbered in the order you use them. Inside it, leave the 4 skill zips zipped.

Build the agent

  1. Open Copilot Chat and select Create agent.
  2. If Copilot opens a chat asking you to describe your agent, select Skip. If you see tabs instead, choose Configure, not Describe. The chat would write its own version of the agent and replace what you paste in.
  3. In Name, paste:GOV.UK communications
  4. In Description, paste:Drafts and reviews UK government customer communications using generic case patterns, GOV.UK style and privacy checks. Uses your service's facts and flags anything not decided.
  5. Instructions: open "1 Paste into Instructions.txt", select everything, and copy and paste it into the box. Scroll to the end to check it pasted whole. The last words should be "Open Government Licence v3.0." If they're not, clear the box and paste again.
  6. Skills: upload each of the 4 zip files in "2 Upload these 4 skills", one at a time. Don't unzip or rename them. If there's no Skills section, upload the 4 files in "3 No Skills option - upload these as knowledge instead" under Knowledge instead. If there's no upload option there either, skip this step.
  7. Web search: switch it off. The skills must never treat a service's published content as its policy, and the Claude version doesn't search unless asked.
  8. Other settings: switch off Create images and Discourage model knowledge. Discourage model knowledge would limit the agent to the files you added, which hold the guidance but not the plain English it needs to write with.
  9. Starter prompts: add these, title then message. Set up my service Help me set up a service context for my service, so you can draft messages for it. Draft a message Draft an email and a text message telling someone we've received their application. Review a message Review this email against GOV.UK style, and tell me what it reveals about the person. Plan a case journey Help me plan the messages someone gets from applying to getting a decision.
  10. Select Create.

Check it worked

Open the agent and try a starter prompt. It should ask about your service, or draft with placeholders and list what still needs a decision. It should not guess your timescales or policy.

To share it, use Share to send a link to people in your organisation, if your organisation allows it. People outside it need to follow these steps themselves.

If it goes wrong

There's no Create agent button

Your organisation has switched agent creation off. Only your IT service can change that.

The instructions were cut short

Clear the box and paste again, then check the last words are "Open Government Licence v3.0." The full text fits inside Copilot's 8,000-character limit.

There's no Skills section, or no Upload files option under Knowledge

What you can add depends on your account and your organisation's settings. Skills are a newer Copilot feature that not every organisation has switched on, and uploading knowledge files may need a paid Copilot licence. Use whichever you have. If you have neither, skip the step: the instructions carry the core rules and the agent works from them alone.

Linking to the files on GitHub doesn't work instead. Copilot searches linked sites rather than reading whole files.

The upload can't find the files, or won't take them

You're probably looking inside the zip without having unzipped it. Close the upload window, unzip the download as described above, and upload from the folder that appears. For skills, upload each zip file itself, not a folder.

It ignores the detailed guidance

The core rules are in the instructions and always apply. The patterns and style guidance are in the skills or knowledge files. Naming the job usually helps, like "use the case communication patterns to draft this".

The skills have been updated

Updates aren't automatic. Download the new zip, paste the new instructions and replace the skills or knowledge files.

Questions

Is it free?

Yes. You need access to the AI tool you install it in.

Can I share it or change it?

Yes. It's licensed under the Open Government Licence v3.0. You can use, share and adapt it, as long as you credit it. Every file in the Copilot download carries a credit line. Keep it in anything you share.

Will my organisation allow it?

None of the routes needs admin rights, but each depends on a setting your organisation controls. Some organisations limit Claude plugins, and Copilot needs agent creation switched on.

Does anything I paste get sent to you?

No. The skills are written instructions with no code in them. There's no server and no account, so nothing you paste is sent to us or stored by us.

Your conversations are handled by the company behind the tool you use, under your plan or your organisation's agreement. Your organisation's rules on personal data still apply. Check what your organisation allows before you paste in real case details.

Does it know my service's rules?

No. It works for any government service and holds no service's rules. You tell it about your service, and it helps you write a service context to keep in your own files. Anything your service hasn't decided is listed for a person to decide.

How do I update or remove it?

A Claude plugin added from GitHub updates itself. Everything else stays at the version you installed: to update, repeat the steps with the new download. To remove it, switch it off or delete it where you added it.

Tell us when it goes wrong

Say which tool you used, and for Copilot whether you added skills, knowledge files or neither. Remove anything identifying first, then open an issue on GitHub.
