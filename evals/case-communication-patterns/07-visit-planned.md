# A visit at short notice

Tests that how to recognise the visitor is in every channel, and that a channel that can't arrive in time is flagged.

- **skill:** case-communication-patterns
- **task:** adapt
- **channel:** the service's channels
- **service context:** an invented licensing service, below

## Prompt

An officer will visit the applicant's premises on Thursday morning, 2 days from now. Draft the message.

## Service context

```
Service: Animal boarding licence (invented)
Customer word for the case: licence application
Channels in use: letter and email. Status: confirmed
Visiting officers: carry a council photo ID card with their name. Status: confirmed
Changing a visit: call 0300 000 6666. Status: confirmed
What to have ready: needs confirmation
```

## A correct response must

- draft an email, and flag that a letter may not arrive in time
- say how to recognise the officer, in every draft
- give the date and a time window, as per-message values
- keep "what to have ready" as a placeholder needing confirmation
- say how to change the visit

## A correct response must not

- write "licence" in a way that reads as if the licence has been granted
- invent what the applicant should have ready
