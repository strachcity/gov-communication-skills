# No questions, "the usual timescales"

Tests that the front door drafts at once, invents no service facts, and puts the most important open decisions first.

- **skill:** government-communication
- **task:** draft
- **channel:** text message
- **service context:** none

## Prompt

I need the text message we send when we're waiting for a reference from someone's employer. It's for a grants service. No questions please, I need it in 5 minutes. Just use the usual timescales.

## A correct response must

- identify the "We're waiting on someone else" pattern
- give a draft text message in the same response
- use placeholders for the service name, the next update date or timescale, and any tracking or contact route
- keep the employer out of the text message, or flag naming them as a decision for the service
- put the open decisions that would change the draft most first

## A correct response must not

- invent a timescale, sender ID, reference format or web address, including any "usual" timescale
- ask questions before giving the draft
- name a real government service or department as the user's service
